> Skills and workflows distilled from real-world AI product management.

## About · 为什么有这个仓库

我是一名 AI 产品经理。这个仓库记录我在日常工作中逐渐形成、反复使用，并尝试通过 AI 复用的一些工作方法。

产品工作中，有些问题会反复出现：

- **竞品分析**收集了很多功能和截图，却没有回答真正待决策的问题。
- **PRD 写作**描述了完整的功能和交互，却没有讲清为什么做、为什么选择这个方案。
- **研发评审**到了细评才发现状态、边界条件和责任归属没有定义清楚。
- **业务复盘**容易停留在指标变化和工作完成情况，却没有解释原因与下一步判断。

这些问题不是简单让 AI「帮我写份文档」就能解决的。我尝试把工作中积累的处理方法整理为 Skills，让 AI 在面对相似任务时，可以复用一套清晰的步骤、判断标准与检查要求，而不是每次从头解释。

**我希望沉淀的不只是 Prompt，而是可复用、可检查、可持续改进的工作方法。**

Skills 帮助我减少重复性的整理、分析与检查工作，但不会代替产品经理对证据、取舍和最终结果负责。

## Workflow & All Skills · 工作流与全部 Skills

这些 Skill 可按需组合，而不是每个项目都必须依次执行。我通常从明确问题开始，经过证据收集、产品判断、方案设计、研发协作与结果复盘，再把新经验继续沉淀下来。

### 日常工作流

这部分按真实工作任务组织，不区分 Skill 是自己沉淀还是来自开源社区。它是一张按需导航图，不是每个项目都必须从头走到尾的固定流程。

### 1. 获取行业与外部信号

- `ai-frontier-digest`：扫描并核验当天真正重要的 AI 模型、产品与 Builder 一手动态。
- `follow-builders`：持续追踪 AI Builder、播客和博客内容。

### 2. 从材料中形成判断

- `signal-to-judgment`：把杂乱反馈、研究和数据转成问题、解释、证伪条件和有边界的判断。
- `executive-product-judgment`：在需求、方案、实验复盘或方向选择中识别主要矛盾、业务结果和机会成本。
- `grilling` / `grill-me`：通过逐轮追问暴露计划中的未决问题、依赖和隐含假设。

### 3. 判断一个具体需求是否值得进入方案阶段

- `product-decision-review`：在需求进入 PRD、设计或开发前，判断用户问题、受益与受损群体、证据、取舍和最短验证路径。

### 4. 用外部证据减少产品决策的不确定性

- `decision-driven-competitive-analysis`：围绕一个真实待决策问题选择样本、比较同一段用户任务，并明确竞品证据的迁移边界。

### 5. 组织方案和 PRD 的判断链

- `prd-strategic-framing`：讲清为什么做、为什么选择这种方案、本期做什么以及结果如何解释。
- `human-ai-collaboration-design`：为复杂研究、分析、规划和写作设计人机分工、检查点与最终责任。

### 6. 快速制作界面或原型

- `frontend-design`：在 Vibe Coding 中建立更明确的主题、字体、色彩和版式方向，减少模板化设计。

### 7. 在正式研发细评前补齐需求

- `engineering-prd-review`：从系统行为和实现边界检查 PRD 是否已达到可设计、可估时、可开发、可测试的程度。

### 8. 汇报、评审和推动决策

- `pyramid-communication`：把方案、复盘、报告和演示材料组织成结论先行、层级清楚的表达。
- `reader-first-business-writing`：按读者角色和业务逻辑重构周报、方案、经营复盘与决策材料，补齐结果归因、信息取舍和行动闭环。

### 9. 设计并交付可投递简历

- `resume-story-design`：把真实经历整理成清晰的求职叙事，完成信息层级、版式设计、A4 PDF 与链接验收。

### 10. 把新的经验继续沉淀成能力

- `skill-creator`：创建、修改、评测和迭代 Skill。
- `find-skills`：先检查社区是否已有合适能力，再决定安装、适配或自己创建。

### 安装与更新

将这个仓库添加为 Codex 插件市场：

```bash
codex plugin marketplace add echo-builds/my-codex-skills
```

然后在 Codex 或 ChatGPT 桌面端的 Plugins Directory 中选择该市场，并按需安装插件。安装或升级后，新建任务以加载最新版 Skill。

更新已添加的市场：

```bash
codex plugin marketplace upgrade personal
```

查看当前市场：

```bash
codex plugin marketplace list
```
