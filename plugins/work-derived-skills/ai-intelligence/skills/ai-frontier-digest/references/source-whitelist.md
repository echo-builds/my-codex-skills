# 一手信息源白名单

这是一份可维护的起始名单，不是排名，也不是穷举。扫描时优先查看官方新闻、研究、文档、模型卡、GitHub Release、Changelog，以及下列人物的原始账号或完整访谈。新增来源必须满足“长期稳定地产出一手信息”这一条件。

## Tier 1：前沿模型与研究机构

- OpenAI：News/Research、API 与产品 changelog、模型卡、官方 GitHub
- Anthropic / Claude：News、Research、Claude/Claude Code 官方资源与 changelog
- Google DeepMind / Google AI：Research、Google Blog、AI Studio/Gemini API 更新
- Meta AI / Meta Superintelligence Labs：官方研究、模型卡、Meta 官方 Hugging Face 组织
- xAI：官方博客、模型卡、API 文档
- Mistral AI：News/Research、文档、官方 GitHub/Hugging Face
- Microsoft AI / Microsoft Research / Azure AI：官方博客与产品更新
- NVIDIA Research / NVIDIA Developer：研究、模型与推理基础设施更新
- Amazon AGI / AWS AI：研究与产品发布
- Apple Machine Learning Research：论文与系统能力发布
- Cohere、AI2、Hugging Face、Stability AI、Black Forest Labs、Runway：官方发布、模型卡和代码

## Tier 1：中国模型与产品团队

- DeepSeek、阿里通义千问 Qwen、字节跳动 Seed、Moonshot AI/Kimi、智谱 GLM、MiniMax
- 百度文心、腾讯混元、阶跃星辰、面壁智能、上海 AI Lab
- 优先使用团队官网、技术报告、官方 GitHub/Hugging Face/ModelScope 和正式产品公告；社媒搬运不作为最终来源。

## Tier 1：AI 产品与基础设施

- Cursor/Anysphere、Replit、Cognition/Windsurf、GitHub Copilot、Vercel
- Perplexity、Lovable、Figma、Notion、Glean、Harvey
- ElevenLabs、Runway、Midjourney、Suno、Pika、Adobe Firefly
- LangChain/LangSmith、LlamaIndex、Weights & Biases、Modal、Together AI、Fireworks AI

只收会改变用户能力、工作流、部署/价格/权限或可靠性的更新；普通模板、客户案例和小幅 UI 调整通常不收。

人物动态只有在包含新事实、方法、数据或清晰行业判断时收录。招聘、活动宣传、转发、情绪表达和无信息量短帖跳过。

## 原始访谈与长内容

- No Priors、Latent Space、Dwarkesh Podcast、Lenny’s Podcast
- Acquired、20VC、Sequoia/YC 官方访谈、公司官方 YouTube/播客

必须链接到具体一期视频、音频或逐字稿，不要只链接频道首页。摘要以完整对话为依据，不能只根据标题或第三方摘录。

## 仅作查漏雷达，不直接进入简报

- Reuters、Financial Times、Bloomberg、The Information、TechCrunch、The Verge、Wired
- Hacker News、Reddit、GitHub Trending、Product Hunt、AI 社区与聚合榜单

这些渠道可以提示“今天也许发生了重要事件”，但最终收录前必须回到官方原文。确实不存在一手公开材料时，不收录并保留不确定性。
