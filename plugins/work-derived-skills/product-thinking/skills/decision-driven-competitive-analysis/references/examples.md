# “出题练习”项目中的真实弯路与纠偏

这份材料是本 Skill 的经验来源，不是其他项目照抄的范例库。使用时迁移纠偏动作，不迁移具体产品结论。

## 项目从什么问题开始

团队已经具备自然语言出题能力，并可根据用户表达交付 Markdown、Quiz 或 PDF，但还不知道核心用户场景和下一步应如何投入。

研究最初同时想回答：

- 还有哪些练习场景；
- 当前一句话出题是否有效；
- 问答中的练习应该做成什么样；
- 手机端怎样练习；
- 诊断、错题、复习、打印等方向是否值得做。

因为判断任务没有收住，竞品范围不断扩张。

## 弯路一：先广泛找产品，再从产品中寻找问题

研究扫描了通用 AI、练习产品、拍搜批改、自适应学习、题库和开源项目。看到什么能力，研究问题就跟着移动：

```text
看到诊断产品 → 研究诊断后推荐课程还是练习
看到自适应学习 → 研究薄弱点和长期掌握度
看到对话产品 → 研究纯对话能否承载练习
看到手机练习 → 研究拖拽、语音和点选
```

这些内容增加了行业知识，却没有减少“问答中的练习怎样设计”的不确定性。

纠偏：先明确待决策问题，再选择可能改变该选择的竞品片段。

## 弯路二：按产品类型组织，压扁了用户任务

产品曾被归为对话生成型、课程练习型、问题补弱型。分类没有错，但无法解释用户拿到题后怎样确认、调整、作答、求助、反馈和转线下。

纠偏：把分析单位从“产品是什么”改为“用户任务在哪一步发生断点”，沿同一任务链看不同产品。

## 弯路三：链接、截图和结论对不上

早期材料中出现过：

- 官网首页代替功能入口；
- GitHub README 代替真实体验；
- 宣传图代替连续操作流程；
- 单张截图承担完整机制结论；
- 未区分亲自体验、官方说明和推测。

纠偏：建立体验证据卡。每个产品必须说明场景、直接入口、连续路径、页面证据、证据强度，以及每张图究竟证明什么。

## 弯路四：功能考古没有回答决策

研究曾详细区分多个产品在诊断后推荐练习、微课还是知识主题。信息准确，但没有解释它如何影响问答中用户表达练习需求后的产品选择。

纠偏：继续研究前先问——即使把这个问题研究清楚，会改变我们哪个产品选择？答不出来就停止深挖。

## 弯路五：从竞品事实越级推导我方方案

### Q-Chat 下线

可观察事实：对话主导型练习曾存在，后来下线。

不能直接推出：对话练习不成立，或结构化 Quiz 天然更好。下线可能涉及使用率、商业策略、资源调整和产品整合等多种原因。

可保留的判断：这种形态在体验上可行，但长期价值仍需其他证据。

### StudyFetch、RemNote 区分学习／测试模式

可观察事实：不同目标下使用不同反馈策略。

不能直接推出：开放问答也必须要求用户手动选择模式。

我方假设：可根据用户表达和行为推断目标，并允许随时纠正；需要自行验证。

### Wayground、Diffit 先审题再发布

可观察事实：题目内容确认和最终交付形态可以解耦。

迁移边界：其核心用户多为教师，愿意承担较高审题和编辑成本。

不能直接推出：普通学生也需要完整编辑器，或一定愿意先预览。

我方假设：先展示少量真实题目，再情境化提供练习或打印入口；需要实验验证。

## 弯路六：把产品假设写成竞品洞察

“先给两道样题”“默认逐题练”“题后推荐 Quiz”“看不到题导致点击低”等都是可能成立的产品假设，但竞品并未直接证明。

纠偏：固定拆成观察事实、机制解释、迁移边界和我方假设四层。

## 弯路七：手机端分析混合了不同层次

选择、拖拽、语音、纸笔拍照、渐进输入、重新设计题目曾被并列为“手机端体验”。它们实际属于不同层次：

1. 任务与题目设计；
2. 作答输入方式；
3. 难度递进；
4. 手机与纸张的场所分工；
5. 反馈和再练策略。

纠偏：先拆层，再分别寻找机制样本和对照样本。

## 后来真正有效的证据缺口

研究开始围绕下列问题组织后，竞品才真正改变判断：

1. 用户意图模糊时，竞品如何开始任务？
2. 用户看到真实内容前，是否必须先选择使用形式？
3. 用户如何发现还可以在线练、打印或逐题完成？
4. 自由对话和结构化作答如何在同一任务中衔接？
5. 系统需要掌握哪些状态，才能针对当前卡点提供帮助？
6. 线下完成后如何回到原任务？
7. 用户离开究竟代表流失、完成还是转移场所？

不同产品只负责补其中一段证据：

| 样本 | 可以帮助理解 | 不能单独证明 |
|-|-|-|
| Q-Chat | 对话可以组织练习 | 对话形态具有长期价值 |
| StudyFetch、RemNote、Brainly | 结构化作答可以接入对话帮助 | 当前产品必须采用相同页面结构 |
| Brilliant | 掌握操作过程能支持更针对性的介入 | 所有学科都适合高度交互化题目 |
| Wayground、Diffit | 内容确认和交付形态可以解耦 | 普通学生愿意使用教师式编辑流程 |
| Duolingo、Quizlet | 移动练习可降低输入成本并渐进增加难度 | 其留存机制可以直接迁移到开放问答 |
| 纸质练习回流流程 | 线下作答可以通过任务身份回到线上 | 普通用户一定愿意扫描上传 |

## 最终沉淀出的经验

竞品分析的有效产物不是产品清单，而是：

> 哪些机制已有较强证据支持，哪些只是基于竞品的迁移判断，哪些关键问题仍必须依靠自己的用户、数据和实验回答。
