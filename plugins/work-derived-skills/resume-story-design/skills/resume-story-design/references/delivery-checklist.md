# Resume delivery checklist

Use this checklist when the task includes a final PDF or other submission-ready artifact.

## Before export

- Confirm the latest approved wording, ordering, dates, organizations, roles, and links.
- Confirm the intended page count and paper size.
- Remove editor controls, debug marks, annotations, and accidental footer text from the printable view.
- Ensure the source uses fonts and assets that will render reliably in the export environment.

## Visual verification

Render every page to an image and inspect the actual output, not only the browser view.

Check:

- outer margins and page edges;
- column widths and shared alignment axes;
- section spacing and repeated-item consistency;
- line wrapping, orphaned punctuation, and isolated percentages;
- timeline continuity and node alignment;
- accidental dead zones, overlap, clipping, and overflow;
- bottom breathing room;
- photo crop and image quality;
- legibility at ordinary viewing size.

If a problem is visible, fix the underlying grid, spacing, width, grouping, or print behavior before adding one-off offsets.

## Functional verification

- Confirm the PDF page count and dimensions.
- Inspect PDF link annotations, not just HTML anchor tags.
- Open representative links and verify that each points to the correct project.
- Flag local-only URLs, expired preview servers, inaccessible files, and other non-portable links.
- Confirm that the PDF opens without errors and that text remains selectable when expected.

## Handoff

Provide:

- the final PDF path or downloadable artifact;
- the editable source path when applicable;
- a concise summary of what changed;
- any remaining limitation that affects submission or sharing.

Do not describe planned checks as completed checks.
